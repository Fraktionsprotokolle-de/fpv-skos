Willkommen im FPV-Editor

Mit diesem Programm bearbeiten Sie die Vokabulardatei fpv.ttl sicher über Formularfelder, ohne selbst Turtle-Syntax schreiben zu müssen.

  1. Öffnen Sie Ihre fpv.ttl-Datei.
  2. Wählen Sie links einen Eintrag aus oder legen Sie über „＋ Neuer Eintrag“ einen neuen an.
  3. Sie können mehrere Einträge nacheinander bearbeiten und zum Schluss gemeinsam speichern (Strg+S). Vor jedem Speichern wird automatisch eine Sicherung angelegt.

Kein Konzept ausgewählt. Wählen Sie links einen Eintrag oder legen Sie über „＋ Neuer Eintrag“ einen neuen an.
